# 한강라이드

아라뱃길에서 여의도 자전거길 종점까지 타는 모바일 3D 라이딩 게임.

플레이: https://skdanieloh.github.io/hangang-ride/

아이폰에서는 Safari로 연 뒤 **공유 → 홈 화면에 추가** 하면, 한 번 받아 둔 뒤 밖에서 와이파이 없이 실행할 수 있습니다.

- 코스: 걸포동 → 아라뱃길 → 고촌 → 한강 남단 → 여의나루역
- 자전거 3종: Giant SCR / Black Fixie (최고 65km/h), 따릉이 (최고 36km/h)
- 앞·뒤·좌·우 터치 버튼, 픽시는 드리프트

로컬 실행:

```bash
npm install
npm run dev
```
